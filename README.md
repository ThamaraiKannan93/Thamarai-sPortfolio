# Thamarai Kannan A — Portfolio

A responsive, static portfolio built with HTML, CSS and JavaScript.

## Included
- Resume-based About, Skills, Experience and Education sections
- LinkedIn, email and phone links
- Selected project links for Area51 Car Care and FarmBrain
- Professional projects from the supplied resume
- Responsive mobile navigation
- Netlify-friendly static structure

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to Netlify
1. Create a GitHub repository.
2. Upload `index.html`, `css/`, `js/`.
3. In Netlify, choose **Add new project → Import an existing project → GitHub**.
4. Select the repository.
5. For a plain HTML site, leave the build command empty and publish the project root.
6. Deploy.
